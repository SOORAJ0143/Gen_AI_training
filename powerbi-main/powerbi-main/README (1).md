# Executive Sales & Profitability Dashboard

## Project

Power BI Executive Dashboard using the Superstore dataset.

## Features

- Total Revenue
- Total Profit
- Profit Margin %
- Total Orders
- Monthly Revenue & Profit Trend
- Profitability by Sub-Category
- Regional Revenue Contribution
- Discount Impact on Margins
- Category & Product Matrix

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Superstore Dataset

## Dashboard

This project contains an interactive Executive Sales & Profitability Dashboard created in Power BI.
